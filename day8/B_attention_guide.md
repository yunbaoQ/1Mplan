# Day8 B：逐格运行的Attention入门｜150分钟

## 先理解用途：根据当前需要，从其他位置汇集信息

可以联想成查资料：你问“CUDA拷贝为什么慢”，手上有三份笔记，分别讲CPU缓存、GPU数据传输和Git操作。你的问题对应Q，每份笔记可供比较的标签对应K，笔记可提供的内容对应V。先比较问题和标签得到相关分数，再把分数变成参考比例，最后按比例汇集内容。这是帮助理解的比喻：真实Q/K/V是向量，内容融合也是数值运算，不是把文章文字按百分比拼接。

| 实验操作 | 查资料的联想 | 在Attention里的作用 |
| --- | --- | --- |
| Q的一行 | 一次查询：我现在需要什么？ | 当前这个位置的查询向量 |
| K的一行 | 某份资料用于匹配的标签 | 判断某个位置和查询是否匹配 |
| V的一行 | 同一份资料提供的内容 | 真正被混合进输出的信息 |
| Q @ K.T | 每个问题都和每份资料比较 | 得到“查询位置×参考位置”的分数表 |
| 除sqrt(d) | 调整打分尺度 | 缓和维度变大时点积的尺度 |
| softmax | 给参考资料分配比例 | 每个查询的一行权重和为1 |
| weights @ V | 按参考比例汇集内容 | 每个查询得到一份融合后的向量 |

有三个查询和三份资料，所以要做3×3=9次比较。分数表的第i行第j列就是“查询i对参考位置j的分数”。例如score[1,2]对应第二个查询与第三份参考。它不只是矩阵形状恰好能乘出来；每个格子都有明确的比较对象。

联想例子：

- 句子“张三把钥匙交给李四，因为他要开门”。要理解“他”可能指谁，可以从“张三”“李四”“开门”等位置汇集线索。这是解释用途的示意，不代表真实模型必然按某个固定比例关注这些词。
- 翻译时，当前正在生成的目标语言位置可以参考原句不同位置。例如翻译“红色的车”时，生成red和car需要汇集不同的源句信息。Transformer的编码器—解码器Attention用于这种跨序列的信息汇集。
- 生成“我想喝一杯……”的后续内容时，当前表示需要结合前面的“喝”“一杯”等上下文。Attention输出是上下文向量；后续网络再把它变成候选token的分数，并不是这个二维实验直接输出一个词。

这些应用及基本机制见[Transformer原论文3.2节](https://arxiv.org/html/1706.03762v7#S3.SS2)。今天手工给Q/K/V，相当于把一小段真实模型内部计算放大来看；通常真实模型从输入表示经过不同的可学习线性变换获得Q/K/V。

对你AI Infra主线的用途：之后学习长上下文、KV缓存和推理性能时，能看懂到底在缓存哪份K/V、在与多少位置比较、哪里涉及矩阵乘法和中间结果。今天先理解这段计算，不要求掌握缓存或性能优化。

你笔记中的第一问需要澄清：开头[1.7,1.1]仅由人工指定的[0.2,0.3,0.5]得到。后面的Attention比例由Q/K决定，**无需解方程或控制权重来凑成[1.7,1.1]**。你对softmax公式和零查询产生均等权重的方向已经理解；均等时，每个输出分量分别等于V相应列的平均值。

你今天要做的是：把三行数据按不同的比例混合，得到三行新的数据。先用人为指定的比例看懂“混合”，再让Q和K算出这些比例。下面是教学示例，你需要自己创建Notebook、逐格运行、检查输出并写自己的解释。指南里的预期不算你的实际结果。

## 第0步：准备文件｜10分钟

在VS Code的day8文件夹新建`attention_practice.ipynb`，选择之前能正常import torch的torch311内核。每段代码放一个代码格，依次运行；格子没运行时后面的变量就不存在。先在第一格运行：

```python
import math
import torch

torch.set_printoptions(precision=4, sci_mode=False)
```

今天用CPU浮点数。`@`表示矩阵乘法，`*`表示逐元素乘法；后面各自有用途。

## 第1步：人为给比例，混合三行｜25分钟

三行数据分别是`[1,0]`、`[0,2]`、`[3,1]`。现在规定它们分别占20%、30%、50%。先算第一列：0.2×1+0.3×0+0.5×3；再算第二列：0.2×0+0.3×2+0.5×1。把你算的结果先写在Markdown格，再运行：

```python
V = torch.tensor([
    [1.0, 0.0],
    [0.0, 2.0],
    [3.0, 1.0],
])
ratios = torch.tensor([0.2, 0.3, 0.5])

pieces = ratios[:, None] * V
mixed = pieces.sum(dim=0)

print("每一行乘自己的比例：\n", pieces)
print("三行加起来：", mixed)
print("矩阵乘法得到同样的结果：", ratios @ V)
```

`ratios[:, None]`把三个比例从形状(3,)变成(3,1)，以便每行两个数都乘同一个比例。`sum(dim=0)`把三行相加，保留两列。预期混合结果为`[1.7,1.1]`，用它核对自己的手算。

目前你已完成“比例×每行，再相加”。Attention最后一步就是这样的加权和。

## 第2步：用Q和K算相关分数｜30分钟

这次比例不提前指定。Q每一行是一次查询，K每一行是可比较的位置。Q的一行依次与K的三行算点积，得到三个分数；分数决定之后混合V时采用的比例。

先看第一行Q=[1,0]：与K第一行[1,0]相乘再相加，是1×1+0×0；与K第二行[0,1]是1×0+0×1；与K第三行[1,-1]是1×1+0×(-1)。先写下这三个数，再运行：

```python
Q = torch.tensor([
    [1.0, 0.0],
    [0.0, 1.0],
    [1.0, 1.0],
])
K = torch.tensor([
    [1.0, 0.0],
    [0.0, 1.0],
    [1.0, -1.0],
])

raw_scores = Q @ K.T
print("Q/K/V的shape：", Q.shape, K.shape, V.shape)
print("K转置的shape：", K.T.shape)
print("相关分数：\n", raw_scores)
print("分数shape：", raw_scores.shape)
```

这里Q是3×2，K.T是2×3，乘积是3×3。分数表的行表示“哪个查询”，列表示“与哪个K比较”。第一行预期是`[1,0,1]`。

今天这三套矩阵是手工指定的教学数据。实际模型通常从输入经过各自的可学习线性变换得到Q/K/V，这部分后续再接起来；它们不是训练中的参数w和b。

## 第3步：分数变成比例｜30分钟

普通缩放点积Attention先除以查询/键的维度的平方根。这里每行有两个数，所以除以sqrt(2)。这个缩放用来缓和维度变大时点积的尺度，不能理解成“把分数直接变成百分比”。

接着softmax把一行三个分数变成三个非负比例，每行相加为1：先分别取指数，再除以同一行指数之和。[官方softmax定义](https://docs.pytorch.org/docs/2.11/generated/torch.nn.functional.softmax.html)

```python
d = Q.shape[-1]
scores = raw_scores / math.sqrt(d)
weights = torch.softmax(scores, dim=-1)

print("缩放后的分数：\n", scores)
print("每行的混合比例：\n", weights)
print("每行比例的总和：", weights.sum(dim=-1))
```

对于这里的二维矩阵，`dim=-1`是最后一个维度，也就是列方向：每一行单独在自己的三列之间分配比例。第一行的第1与第3个分数相同，所以相应比例也应相同；中间分数较小，其比例较小。只看输出的第一行，说明这个关系。

softmax不是“每个原始分数除以原始分数总和”；原始分数可能为负数，也可能总和为0。

## 第4步：每个查询各得到一行混合结果｜25分钟

weights第一行给查询0使用，第二行给查询1，第三行给查询2。每个查询都根据自己的比例混合V的三行：

```python
output = weights @ V
first_row_check = (
    weights[0, 0] * V[0]
    + weights[0, 1] * V[1]
    + weights[0, 2] * V[2]
)

print("Attention输出：\n", output)
print("输出shape：", output.shape)
print("单独展开第一行：", first_row_check)
print("两种写法一致：", torch.allclose(output[0], first_row_check))
```

output预期是3×2：三个查询各得到一个两维输出。先用你打印的第一行比例手算两个数，再核对程序，不只是查看True。

完整计算路线是`Q @ K.T → 除sqrt(2) → 每行softmax → 权重 @ V`。它对应[官方Attention参考实现](https://docs.pytorch.org/docs/2.11/generated/torch.nn.functional.scaled_dot_product_attention.html)中的基本计算；今天B尚未加入mask。

## 第5步：只改第一行Q做一次对照｜15分钟

先预测：如果第一行Q全是0，它与所有K的点积是否一样？三个分数一样时，三个比例是否应该一样？先把预测写出来，再运行：

```python
Q_changed = Q.clone()
Q_changed[0] = 0.0

scores_changed = (Q_changed @ K.T) / math.sqrt(d)
weights_changed = torch.softmax(scores_changed, dim=-1)
output_changed = weights_changed @ V

print("改动前第一行权重：", weights[0])
print("改动后第一行权重：", weights_changed[0])
print("改动后第一行输出：", output_changed[0])
print("其余两行是否保持原样：",
      torch.allclose(output_changed[1:], output[1:]))
```

`clone()`用于保留原Q，方便比较。这里仅改变Q第一行，K/V固定；记录实际结果，并说出为什么其他两行保持原样。这个对照属于原B任务，不是增加新作业。

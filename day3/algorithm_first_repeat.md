# 算法自测：第一个重复任务编号

自拟入门题，适合当前 C++ 序列/哈希练习。不是 LeetCode 官方题目，不赋予平台数值评分。今天算法总预算40分钟，沿用原安排。

## 题目

推理服务按顺序收到一组整数任务编号 ids。返回最早出现的重复编号所对应的两个下标 {left, right}。

规则：
- 下标从0开始，left < right，且 ids[left] == ids[right]。
- 选择 right 最小的一对；同一个编号出现多次时，left 取该编号第一次出现的位置。
- 没有重复编号时返回 {-1, -1}。
- 只返回结果，不修改输入数组。

函数签名：
```cpp
std::pair<int, int> firstRepeat(const std::vector<int>& ids);
```

约束：0 ≤ ids.size() ≤ 200000；每个编号在 [-1000000000, 1000000000] 范围内。

## 样例

| 输入 | 输出 | 说明 |
| --- | --- | --- |
| [8, 3, 8, 3] | {0, 2} | 8先发生重复 |
| [5, 2, 2, 5] | {1, 2} | 按第二次出现位置判断，不按编号大小或首次位置 |
| [4, 7, 9] | {-1, -1} | 无重复 |
| [6, 6, 6] | {0, 1} | 返回最早形成的一对 |

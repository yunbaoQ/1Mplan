## A. 现有环境验证 + 硬件概念（120 分钟）

**环境验证（60 分钟）：**激活自己已有的 Conda 环境，将 `你的环境名` 换成真实名称。下列命令用于自查，不用重装环境。

```powershell
conda env list
conda activate 你的环境名
python -c "import sys, torch, torchvision; print('python:', sys.executable); print('torch:', torch.__version__); print('torchvision:', torchvision.__version__); print('cuda_available:', torch.cuda.is_available()); print('torch_cuda_build:', torch.version.cuda); print('gpu:', torch.cuda.get_device_name(0) if torch.cuda.is_available() else 'CUDA GPU unavailable in this environment')"
```

记录输出至 environment_check.txt，并记录电脑 CPU 型号、内存容量、GPU 型号。CUDA 为 False 仅说明当前环境不能使用 CUDA，不能证明电脑没有 GPU。若报错，先保留完整报错，发到本聊天再定位。

**硬件概念（60 分钟）：**理解 CPU 执行指令与控制、GPU 的大量并行计算、RAM 放运行中的程序与数据、显存放 GPU 使用的数据、磁盘持久保存文件。画“磁盘 → 内存 → CPU/GPU”的示意图，解释一个张量为何要从 CPU 设备迁移到 GPU。暂不要求学 CUDA 或完整计算机组成课程。

验收：environment_check.txt + hardware_basics.md；用自己的话解释内存、显存与磁盘的区别。
